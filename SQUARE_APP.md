## Installation

### Step 1: Install from Square App Marketplace

1. Visit the **Square App Marketplace**
2. Search for "Multi-Channel Manager"
3. Click **"Add to Square"**
4. Review the permissions requested
5. Click **"Allow"** to authorize the app

### Step 2: Automatic Setup

The app automatically:
- Creates your account
- Imports your Square catalog
- Syncs all locations
- Configures default settings

### Step 3: Complete Onboarding

1. Set your password
2. Configure business preferences
3. Review inventory settings
4. Choose notification preferences

**That's it! Your Square data is now in the system.**

### Step 4: Connect Additional Channels (Optional)

1. Go to **Settings** → **Channels**
2. Click **"Connect Channel"**
3. Select marketplace (eBay, Amazon, etc.)
4. Authorize the connection
5. Configure sync settings

## Features in Detail

### Inventory Synchronization

**How It Works**:
1. Make a sale on any channel (Square POS, eBay, Amazon, etc.)
2. Inventory automatically decreases everywhere within seconds
3. Low stock alerts prevent overselling
4. Restock in Square, inventory updates on all marketplaces

**Conflict Resolution**:
- If two sales happen simultaneously, first confirmed wins
- Second customer gets "sold out" notification
- You never oversell

**Multi-Location**:
- Each Square location tracked separately
- Allocate inventory to specific channels from specific locations
- Transfer inventory between locations
- Location-specific safety stock

### AI Product Optimization

**Title Optimization**:
```
Before: "Nike Shoes Size 10"

After (eBay): "Nike Air Max 270 Running Shoes Men's Size 10 Black/White New"
After (Amazon): "Nike Men's Air Max 270 Running Shoe, Size 10, Black/White"
After (Etsy): "Vintage Nike Air Max Sneakers - Men's Size 10 - Black & White"
```

Each marketplace gets optimized title with keywords for that platform.

**Description Generation**:
- SEO-optimized bullet points
- Feature highlights
- Sizing information
- Care instructions
- Return policy
- Channel-specific formatting

**Category Mapping**:
- AI analyzes product details
- Selects most relevant category on each marketplace
- Handles marketplace-specific category structures
- Ensures compliance and visibility

### Pricing Intelligence

**Competitor Price Tracking**:
- Monitors competitor prices on eBay, Amazon, Walmart
- Updates multiple times daily
- Tracks price history and trends
- Alerts on significant price changes

**Automated Pricing Strategies**:

1. **Match Competitor**: Always match lowest price
2. **Beat Competitor**: Undercut by $X or Y%
3. **Stay Below**: Never exceed competitor price
4. **Stay Above**: Position as premium (stay above competitors)
5. **Maintain Margin**: Ensure minimum profit margin
6. **Market-Based**: Use average of top 5 competitors
7. **Inventory-Based**: Increase price when low stock, decrease when overstocked
8. **Time-Based**: Different prices for different times/days
9. **Custom Rules**: Build your own complex pricing logic

**Safety Limits**:
- Set minimum and maximum prices
- Profit margin protection
- Maximum price change per day
- Approval required for large changes

### Returns & Refunds

**Customer Return Process**:
1. Customer initiates return (via email, phone, or self-service portal)
2. System creates RMA number
3. Optional: Merchant approves or rejects return
4. Automatic return shipping label generated (ShipStation)
5. Customer ships package back
6. Real-time tracking updates
7. Merchant receives package
8. Inspection: check item condition
9. Automatic refund processing (Stripe, Square, PayPal)
10. Item restocked or disposed based on condition
11. Customer receives refund confirmation

**Merchant Benefits**:
- Streamlined return process
- Reduced customer service time
- Automatic refund to original payment method
- Track return reasons for product improvements
- Sync refunds to marketplaces automatically

## Frequently Asked Questions

### General

**Q: Do I need a Square account?**
A: Yes, Multi-Channel Manager is built specifically for Square merchants. If you don't have Square yet, you can sign up at squareup.com.

**Q: Can I use this without connecting other channels?**
A: Absolutely! The Free tier is perfect for Square-only merchants who want advanced features like returns management, analytics, and AI tools.

**Q: Is my data safe?**
A: Yes. We use bank-level encryption, never store payment card data, and undergo regular security audits.

**Q: Can I cancel anytime?**
A: Yes, cancel anytime. No long-term contracts. Prorated refunds for annual plans.

### Installation

**Q: How long does installation take?**
A: 2-3 minutes. Click "Install" in Square App Marketplace, authorize permissions, and you're done!

**Q: Will it disrupt my current Square setup?**
A: No. The app reads your Square data but doesn't modify your Square configuration.

**Q: What if I have thousands of products?**
A: No problem! The app handles large catalogs efficiently. Initial sync may take 30-60 minutes for 10,000+ products.

### Inventory

**Q: How fast does inventory sync?**
A: Real-time. Inventory updates across all channels in under 5 seconds.

**Q: What happens if two people buy the last item simultaneously?**
A: First confirmed purchase wins. Second customer is notified item is sold out. You never oversell.

**Q: Can I set different inventory levels per channel?**
A: Yes! Allocate specific quantities to each channel, or use shared pool with safety stock minimums.

### Pricing

**Q: Is there a setup fee?**
A: No setup fees. Just monthly subscription.

**Q: What happens if I exceed my product limit?**
A: You'll be prompted to upgrade. We never disable your account without warning.

**Q: Do you take a percentage of sales?**
A: No! We only charge the flat monthly fee. No transaction fees, no commissions, no hidden costs.

**Q: Can I try before I buy?**
A: Yes! The Free tier is perfect for testing. Upgrade when you're ready to connect additional channels.

### Technical

**Q: Do you store my Square credentials?**
A: No. We use OAuth 2.0 tokens provided by Square. You can revoke access anytime from your Square dashboard.

**Q: What if Square's API is down?**
A: The app continues working with cached data. Updates resume automatically when Square's API recovers.

**Q: Can I use the API?**
A: Yes, Enterprise plan includes full API access for custom integrations.

### Returns & Refunds

**Q: Does this handle in-store returns from online purchases?**
A: Yes! Scan the barcode at Square POS to process return, and it syncs everywhere.

**Q: Can customers initiate returns themselves?**
A: Yes, optional self-service return portal for customers.

**Q: Do refunds go back to the original payment method?**
A: Yes, automatically. Or you can issue store credit if preferred.
